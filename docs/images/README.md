# 개발 이미지 기록

이 디렉터리는 프로젝트를 만들고 검증하면서 저장한 이미지를 선별한 것이다. 화면을 새로 그린 목업이나 외부 참고 사이트 캡처가 아니다. 일부는 이전 구현이며, 샘플 데이터가 포함되어 있다. 원본 개인정보·인증 화면·운영 파일은 포함하지 않는다.

- `collection.png`: 원호형 책장과 표지 바깥 이름·분류. 원본 `output/playwright/archive-reference-main.png`.
- `collection-tall.png`: 높이가 다른 책장 검증. 원본 `output/playwright/collection-desktop.png`.
- `collection-mobile.png`: 모바일 예시 책장. 원본 `output/playwright/collection-mobile.png`.
- `cover-transition-start.png`, `cover-transition-end.png`: 표지 열기 전환 중 정지 프레임. 원본 `output/playwright/archive-reference-open-wipe.png`, `archive-reference-cover.png`. 영상이나 GIF가 아니다.
- `early-overview.png`: 아래쪽 중복 소개가 남아 있던 초기 상세. 원본 `output/playwright/overview-inline.png`.
- `early-report-reader.png`: 화살표 중심의 초기 보고서 리더. 원본 `output/playwright/report-desktop.png`. 현재의 연속 PDF 리더와 다르다.
- `folder-layers.png`: 테스트용 폴더와 위층 책자. 원본 `output/inline-introduction-check/folder-layers.png`.
- `editor.png`: 어두운 수정 화면과 실시간 표지 미리보기. 원본 `output/reading-editor-check/editor-preview.png`.
- `pdf-render-test.png`: 테스트용 원본 PDF 렌더 결과. 원본 `output/pdf/cloud-report.png`.

개별 이미지의 정확한 촬영 시각은 추정하지 않았다. README와 개발 일지에서 각 단계의 설명 자료로 사용한다.

- `motion-polish-desktop.png`, `motion-polish-mobile.png`: 2026-11-04 Motion 진입 효과와 조작부 개선 후 격리된 예시 데이터로 확인한 화면. 원본 `output/design-check/ready-desktop.png`, `ready-mobile.png`. 정지 화면이므로 움직임의 전체 시간을 나타내지는 않는다.
